# Genres

Genre tags are only on the decks where genre changes the card: Mechanic, Resource, Progression, Constraint. The other decks fit every genre.

Each card lists every genre it fits. A card that fits every genre lists all 21. There is no "any" tag. The numbers count the cards tagged with each genre. Each genre must have at least 10 cards in each of the 4 decks.
