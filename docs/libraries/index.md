# Card Decks (General)

General versions of the cards in `Card_Decks/`. Game names, places, and lore are removed. Near-equal cards are merged. Cards with no useful general version are dropped.

The "Games" column shows which games the card came from: the Steam Top 250, plus extra games added to fill thin genres (`Extra_Games_cards/`).
