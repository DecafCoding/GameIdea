Modifier combine

There are 3 Modifier decks. Any Modifier can combine with any Player Role, Resource or Setting card, so the user is free to mix them. These examples use the Player Role modifier. The purple zones show where a drop goes. A Modifier on any other deck tucks like a normal card.

The card has no adjectives yet. A drop anywhere on it combines. The Modifier card goes away, and its 4 adjectives become the inner ring.
