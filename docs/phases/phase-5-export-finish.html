User Stories

  • As a game developer, I want the text file to hold each hook sentence, so that my notebook copy has the hooks and not only the cards.
  • As a user with boards in the browser, I want a board file that imports again with nothing lost, so that it is a real backup.
  • As a user who works in daylight, I want Light mode and a theme color I like, applied before the first frame, so that the app never flashes dark at me.
  • As a new user, I want a Settings dialog with the keyboard shortcuts and the app version, so that I can learn the ring keys and know which build I run.
  • As a user who likes a tidy board, I want dropped cards and notes to snap to the dot grid, with Alt to place one freely, so that stacks line up without effort.
  • As a user, I want the board list and the empty board to match the design in every mode and theme color, so that the app feels finished.
  • As the owner, I want every done criterion and target checked, and the LAN build at 4444 confirmed, so that I can hand the app to other people on my network.

Problem Statement

The app works end to end in dark orange only. The text file leaves out the hooks, which are the product's main output. Users cannot change mode or color, cards drop wherever the pointer lets go, the board list still carries TheForge copy, and no check proves the first-load, LAN and full-feature done criteria. Restyle the board list and empty board to design 9.3 / 9.2, fix the light-mode and fixed-warning color rules, and add browser tests for all 6 mode × color combinations on both screens. Finish with first-load, privacy, size and LAN checks and an audit of every carried-over feature.
