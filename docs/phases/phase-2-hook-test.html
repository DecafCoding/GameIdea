Problem Statement

Edge Cases

  • A Hook Card with no tucked card: New state, Copy and Redraw All disabled, sentence "".
  • Top card under the Hook Card is not a Player Role: sentence starts with that badge word, capitalized.
  • 2 cards tucked under one card: read in stack order, matching the badges on the seams.

  • Base card with an on-top card and no merged ring (after Split): edges read "tall pilot"; the next Modifier drop merges.

  • Clipboard blocked: fallback dialog with the text selected.
  • Import of a board file with a dangling onTopOf: accepted, the card shows as a free Modifier.
